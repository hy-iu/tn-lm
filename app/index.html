§1 · 综述报告

MPS 张量网络方法用于深度学习的研究调研
——面向类 LLM 与多模态大模型

矩阵乘积态（Matrix Product State, MPS）及其算符版本（MPO，数学界称张量链 / Tensor Train, TT）是源于量子多体物理的一维张量网络分解方法。过去十年间，它被引入深度学习，并沿三条主线发展：MPS 作为学习模型本身；MPO/TT 用于神经网络与大模型压缩；量子与量子启发的大模型。

执行摘要

主线一，MPS 作为学习模型。2016 年 Stoudenmire 与 Schwab 在 NeurIPS 上用 MPS 加 DMRG 式扫描算法做监督分类，MNIST 测试错误率低于 1%；Han 等人 2018 年在 Physical Review X 上提出 MPS Born machine 做无监督生成建模，被引逾 500 次。

主线二，MPO/TT 压缩。从 2015 年 Novikov 等人的 TT 全连接层压缩，到 2024 年 Multiverse Computing 的 CompactifAI 将 LLaMA-2 7B 压缩至原体积 30%（配合量化后内存缩减 93%、参数减少 70%，精度仅降 2–3%），成为该方向产业化程度最高的成果。

主线三，量子/量子启发大模型。如用张量网络去纠缠器（disentangler）把预训练 LLM 层改写为「变分量子线路 + MPO」混合架构的工作（2024）。

核心结论 MPS/MPO 在 LLM 时代的最大现实价值是可控、可解释的结构化权重压缩——「键维 χ 直接控制压缩率与关联保留量」提供了区别于剪枝、量化、低秩近似的第三条路线。作为独立生成/语言模型，MPS 类模型在小规模与结构化序列任务上表现优异，但尚无证据表明其能在现代 LLM 尺度上与 Transformer 竞争；2026 年的系统性复评表明，训练后张量分解存在由「重尾权重与高秩异常特征」导致的根本性局限。多模态方向上，TFN/LMF 一脉在情感分析类中等规模融合中成熟，但 MPS 类方法在多模态大模型（MLLM）中的应用基本空白。

1 · 数学基础与概念框架

1.1 MPS/TT 与 MPO 的定义

MPS 将一个高阶张量（例如量子态振幅、联合概率或长向量）分解为一串三阶（首尾为二阶）核张量的收缩：cs₁…s_L = Σ As₁As₂…As_L，其中相邻核之间共享的「键」（bond）的维度 χ 称为键维，它是整个框架的核心超参数——χ 越大，能表达的跨二分关联（物理语言：纠缠熵，S ≤ log χ）越强，参数量也越大。Oseledets 2011 年在 SIAM 提出的 Tensor Train 分解与 MPS 在数学上等价，二者分别来自物理与数值线性代数社区。当分解对象是矩阵（如神经网络的权重矩阵 W）时，把输入、输出指标各自拆成多个小指标后做链式分解，得到的结构称为矩阵乘积算符（MPO）；压缩通过逐次奇异值分解（TT-SVD）截断实现，参数量从指数级降为关于 χ 的多项式级。

MPS 具有若干对机器学习极为有用的结构性质：存在规范形（canonical form）使得归一化、采样、内积等操作有高效精确算法；支持 DMRG 式的局部交替优化与自适应键维截断；压缩（rounding）操作有可控误差界。这些性质使得 MPS 模型在理论上更像「白盒」——纠缠熵、量子互信息等量子信息量可以直接计算并用于解释模型学到的特征关联。

1.2 为什么一维链结构适用于序列与权重

MPS 天然匹配一维关联结构（面积律）：一维有能隙量子态的纠缠满足面积律，因此可以被小 χ 的 MPS 高效表示；语言序列具有一定局部性，图像展平后近似满足，这使 MPS 成为序列数据合理的归纳偏置。对于二维或更复杂的关联结构（如高分辨率图像、全局注意力模式），一维链的表达力受限，需要树张量网络（TTN）、PEPS 或 MERA 等更高维结构——这也是后文讨论的若干局限与扩展工作的物理根源。

1.3 张量网络与深度学习交汇的整体图景

多篇综述系统梳理了这一交叉领域：Wang 等人的 "Tensor Networks Meet Neural Networks" 综述覆盖张量化的神经网络各层与 LLM 应用；2026 年的综述 "Quantum-inspired tensor networks in machine learning models" 将应用分为监督学习、无监督/生成建模、模型压缩、可解释性与隐私等类别，指出 TN 的两大独特优势是可直接计算量子信息观测量用于解释，以及存在保持函数不变的局部变换。

2 · 主线一：MPS 作为学习模型

2.1 监督学习：MPS 分类器一脉

奠基性工作是 Stoudenmire 与 Schwab（NeurIPS 2016）：将每个输入像素经局域特征映射后做张量积，得到指数维特征空间，再用 MPS 参数化该空间中的线性分类器，以 DMRG 式双站点扫描算法训练，MNIST 上测试错误率低于 1%，且键维相当小即可。与之独立地，Novikov 等人的 Exponential Machines 从张量分解角度用 TT 格式隐式表示任意高阶特征交互。后续 Google 的 TensorNetwork 库论文用自动微分替代 DMRG 训练 MPS，MNIST 达 98%、Fashion-MNIST 达 88%，且结果对 χ≳10 基本不敏感。

这条线随后扩展到更复杂的视觉任务：基于 patch 的 MPS 医学图像分割、MPS/PEPS 多分类器用于 Fashion-MNIST 与新冠 X 光胸片、以及同时支持分类与生成的 MPS 模型。Jahromi 与 Orús 的变分张量神经网络（VTNN）将 MPO 层嵌入标准深度网络并用 PaL/DMRG 式扫描训练，MNIST 上单 epoch 达 0.958（同条件经典 NN 为 0.942），但也暴露了扫描式训练时间随张量数增长的问题。

2.2 生成建模：Born machine 与自回归 MPS

Han 等人（PRX 2018）提出用 MPS 的模平方表示概率分布（Born 规则），通过相邻核合并—SVD 截断的自适应训练直接建模数据分布并无拒绝精确采样，在 Bars-and-Stripes 与 MNIST 上验证了生成能力，该文被引逾 500 次，是张量网络生成模型的奠基作。Stokes 与 Terilla 提出受 DMRG 启发的无梯度确定性训练算法，在结构化数据上键维 8 的 MPS 几乎完美学习。Liu 等人（PRE 2023）将 MPS 发展为自回归无监督模型，性能可与标准传统模型竞争。

在模型类表达力方面，Glasser 等人（NeurIPS 2019）证明局部纯化态（LPS）等推广形式的表达力层级，Miller 等人进一步建立了 uMPS 与预测态表示（PSR）、加权自动机（WFA）、隐量子马尔可夫模型（HQMM）之间的严格等价与包含关系——Born machine 子类等价于二次加权自动机，且存在无法被有限维 Born machine 表示的 HMM，揭示了 MPS 类序列模型的表达力边界。

2.3 序列与语言建模：uMPS 与「语言即 MPS」

Miller、Rabusseau 与 Terilla（AISTATS 2021）的 uMPS（各站点共享同一核的均匀 MPS）是 MPS 用于序列建模的代表作：长度 n 的序列可以 O(log n) 深度并行求值（区别于 RNN 的固有串行），并提出了由正则表达式定义条件分布的新型生成算法，可实现自回归采样、「填空」采样乃至无神经对应物的结构化生成；在 Tomita 文法与真实文本实验中，uMPS 能以小数据泛化到 3 倍于训练长度且保持 90% 以上文法正确率，优于 HMM、单向 LSTM 与（小数据下的）Transformer 基线。

更早的理论工作直接把语言与张量网络联系起来：Pestun 与 Vlassopoulos 2017 年提出 "Tensor network language model"，Pestun 等人提出 "Language as a matrix product state"，从范畴论与概率形式语言角度构造语言的 MPS 表示；Gallego 与 Orús 的 "Language design as information renormalization"（2022）把语言设计视为信息重正化过程，提出用纠缠标量刻画语言复杂度的思路。这些工作构成「MPS 原生语言模型」的谱系，但都停留在中小规模验证阶段。

3 · 主线二：MPO/TT 用于神经网络与 LLM 压缩（当前最活跃方向）

3.1 前 LLM 时代：从全连接层到 Transformer

Novikov 等人 2015 年的 "Tensorizing Neural Networks" 首次用 TT 分解压缩稠密全连接层，在保持精度的同时取得数量级参数缩减，是整个方向的源头。Yang、Krompass 与 Tresp（ICML 2017）用 TT 分解 RNN 的 input-to-hidden 矩阵（TT-RNN），使参数量少几个数量级的模型在视频分类上接近 SOTA；随后出现 MPO-LSTM、TR-LSTM（AAAI 2019）、BTT-RNN（CVPR 2018）、Conv-TT-LSTM（NeurIPS 2020）等一系列张量化循环网络。Khrulkov 等人 2019 年提出 TT-embedding：不把训练好的嵌入矩阵事后压缩，而是直接用 TT 核参数化嵌入层并端到端训练，在情感分析、机器翻译、语言建模上大幅压缩且性能几乎无损甚至略升。Ma 等人（NeurIPS 2019）的张量化 Transformer 用块项分解（BTD）构建「多线性注意力」，在语言建模与机器翻译上以更高压缩比取得更好结果。

3.3 产业化进展

Multiverse Computing（西班牙）以 CompactifAI 为核心于 2025 年 6 月完成 2.15 亿美元 B 轮融资，宣称可压缩开源 LLM 达 95%，推理成本节省 50–80%。2025 年 4 月其发布 Llama 3.1-8B 与 Llama 3.3-70B 的压缩版：体积缩减 80%、参数少 60%、能效提升 84%、推理快 40%，已被银行、电信、能源企业 beta 测试。Terra Quantum 的 TQCompressor 是另一家量子公司的同类产品。

3.4 批判性评估与已知局限

2026 年的系统复评 "Rethinking the Role of Tensor Decompositions in Post-Training LLM Compression" 在 GPT-J 6B、LLaMA-2 7B 及 MoE（Qwen3-30B-A3B）上统一评测 Tucker、TT 与矩阵 SVD：结论是张量分解假设的共享子空间与现代 LLM 学到的异质表示存在根本性错配——权重呈重尾分布、高秩异常特征至关重要，导致免训练张量压缩在同等压缩比下显著劣于矩阵方法。其他已知局限包括：一维链结构对非局域关联表达力不足（需 PEPS/TTN）；DMRG 式训练时间开销大且难以在 GPU 上匹敌 Adam；张量化内核若不专门优化，参数减少不一定转化为实际吞吐（Minima 为此专门开发 Triton/CUDA 内核）。当前共识是：MPO/TT 压缩必须配合敏感度分析、修复训练与硬件内核优化才能落地。

4 · 主线三：量子与量子启发的大模型

Aizpurua、Orús 等人的 "Quantum Large Language Models via Tensor Network Disentanglers"（2024）提出把预训练 LLM 层改写为 VQC + MPO + VQC 的混合量子-经典形式：先用张量网络去纠缠器把 MPO 中的纠缠尽可能转移到两个变分量子线路中，残余 MPO 可压缩到键维 1——在 SmolLM2 上，被替换层的经典参数从 110,592 降至约 36（三个数量级），困惑度上升不足 0.3%；再训练附加的酉适配器可使困惑度比原模型再降最多 1.6%，并在真实量子处理器上完成了混合推理验证。更广义的量子 NLP 路线（DisCoCat 范畴语法、量子嵌入等）也有探索，目前均为概念验证规模，其意义在于为「量子硬件承载语言模型子模块」探索路径，而非近期可替代经典 LLM。

5 · 多模态方向：现状与空白

多模态情感分析中的 Tensor Fusion Network（TFN, 2017） 通过对各模态表示做外积显式建模单/双/三模态交互，在 CMU-MOSI 上提升显著，但代价是维度指数爆炸。Low-rank Multimodal Fusion（LMF, 2018） 对融合权重张量做低秩分解，复杂度从指数降为关于模态数线性。这一支脉本质是 CP/低秩张量分解而非 MPS，但证明了「张量结构 + 低秩」对跨模态交互建模的有效性。

视觉侧：MPS/TT 已用于图像分类、高光谱-多光谱图像融合；Partial Tensorized Transformers 同时对 BERT 与 ViT 做嵌入层压缩与部分张量化，报告精度提升最高 5%——而 ViT 正是 LLaVA 等 MLLM 的视觉编码器。直接的 MPS×MLLM 工作目前基本缺失：主流 MLLM 的效率优化走视觉 token 压缩/剪枝路线，而非张量网络。因此「用 MPO 压缩 MLLM 的视觉编码器与跨模态投影器」「用 MPS 表示多模态 token 序列」属于明确的研究空白与机会点。

6 · 独特优势：可解释性、隐私与算法特性

可解释性：TN 可被解释为显式量子态，纠缠熵与量子互信息给出特征复杂度与关联的内在度量，已被用于可解释 NLP 与网络安全场景。隐私：MPS 的结构化参数化被用于增强隐私的学习协议。算法特性：uMPS 序列求值可 O(log n) 深度并行；DMRG 式局部优化可在小 χ 下自适应确定最小参数量，训练成本随样本数至多线性增长；MPS 生成模型支持精确无拒绝采样与正则表达式约束采样，这在神经生成模型中没有直接对应物。

8 · 结论

MPS 张量网络为深度学习提供了一套兼具结构先验、可控近似与物理可解释性的数学工具。对大模型而言，其最现实的价值已被 CompactifAI、Saten、Minima 等工作证实：在关联空间而非神经元计数上做压缩，配合敏感度画像、修复训练与定制内核，可在 7B–32B 尺度上取得体积减半乃至更激进的压缩而精度损失控制在 1–3 个百分点，并已产生数亿美元级的商业转化。与此同时，2026 年的批判性复评提醒我们：免训练张量分解并非免费午餐，现代 LLM 权重的重尾与高秩异常特征构成根本性障碍，张量方法的合理定位是混合压缩工具箱中的结构化组件而非银弹。对研究者而言，多模态大模型的张量化、高维张量网络结构对注意力的适配、训练态原生张量化 scaling 行为，以及 MPS 生成模型的约束采样能力在可控生成中的利用，是未来 2–3 年最值得投入的方向。

§2 · 核心结论

路线选择：以 χ*(W) 标度律为一等公民

课题的科学内核现在可以钉得很死：文本的跨切面互信息随长度近似体积律增长 I(L) ~ L0.82（2103.06872），而 MPS 在任意切面最多携带 log₂χ 比特——χ 对上下文的限制是硬信息论约束，不是调参问题。因此最好的结果不是「绕过这堵墙」，而是定量刻画墙的高度：对每个上下文窗口 W，求模型达到教师性能 x% 所需的最小键维 χ*(W)，判别它对数/幂律/指数增长。

Verdict 推荐路线：原生 uMPS 学生（χ = 历史状态维度，精确可控）+ 135M Transformer 教师 KL 蒸馏 + nanoinfra 训练评测管线，在合成召回探针与真实语料（TinyStories/BabyLM）上扫描 χ×W 网格。两个论据：①「成熟 LLM → 可调 χ MPS 学生」的蒸馏在文献中完全空白（2026 综述仅引 χ=1 退化情形的 KnGPT）；② 成本已被 3090 实测封死——(χ,W) 全网格约 30 runs 仅 2.4 小时。不要走「MPO 压缩现成 LLM 再测上下文」：权重 MPO 的 χ 约束的是权重有效秩而非历史状态维度，且事后张量化已知存在 ≤1.3–1.5× 近乎免费、超过 ~2× 级联崩塌的天花板（compression–realization gap）。

3.5 蒸馏路线：题眼所在

事后张量化预训练 LLM 的工作很多（TensorGPT、CompactifAI、Minima、Saten、KARIPAP，见 §1 与 §5），跨工作的一致规律是：全模型 ≤1.3–1.5× 压缩近乎免费，超过 ~2× 重建误差级联崩塌（LeSTD CR2.5: PPL +459%；LatentLLM CR1.67: +54%；Saten 报告纯 TT 崩塌必须 LoRA 救）。机理已被证明（2606.03465）：Frobenius 最优的 TT/HOSVD 与算子范数保持错配，误差随宽度多项式放大——综述称之为 compression–realization gap（省下的参数换不成加速）。

而真正的 teacher LLM → 可调 χ MPS 学生的 KL 蒸馏（匹配 next-token 边缘分布）在文献中完全空白：2026 年张量方法综述（2608.30505）中「蒸馏进张量化学生」仅引一篇 Kronecker 分解的 KnGPT（ACL 2022），而 Kronecker ≡ χ=1 的退化情形。配合 2504.18574 的发现——Llama-3.1-8B 只有极少数 gather-and-aggregate 头承载召回，剪掉它们 MMLU 从 66% 掉到 25%，即「召回住在窄电路里」——低秩/张量手术很可能恰好切在这条电路上，这为蒸馏路线提供了可证伪的动机。
